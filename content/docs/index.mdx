## Introduction

Welcome to **Krave Docs**.

Krave Docs focuses on browser-based computer vision with **MediaPipe** and **Next.js**. Follow practical guides to add live face detection and hand landmark tracking to your applications.

The examples run directly in the browser and request camera access only when you start a demo.
